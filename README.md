# AI Resume Brutal Roaster

AI Resume Brutal Roaster is an AI-powered resume review tool that gives you honest, direct, and brutally funny feedback on your resume. It identifies weak sections, ATS issues, unnecessary buzzwords, unclear achievements, and suggests better resume bullet points.

## Features
- Upload PDF resumes, images, or paste resume text
- Choose between Mild, Spicy, and Nuclear roast levels
- Get an overall resume score
- ATS and resume flaw analysis
- Identify red flags and weak sections
- Get improved resume bullet points
- View and share previous roast results
- Dark and light mode
- Submit feedback through Formspree

## How to Use
1. Upload your resume or paste the text.
2. Select your preferred roast level.
3. Click the roast button.
4. Review your score, flaws, red flags, and suggestions.
5. Use the improved bullet points to strengthen your resume.

## Tech Stack
**Frontend:** React 18, Vite, Tailwind CSS, Framer Motion, Lucide React, React Router, Canvas
Confetti  
**Backend:** Node.js, Express.js, Multer, PDF parsing  
**AI:** Google Gemini API with a local fallback analysis

**Feedback:** Formspree
