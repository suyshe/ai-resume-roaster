#  AI Resume Brutal Roaster

An AI-powered resume reviewer that gives **honest, direct, and brutally funny** feedback on your resume. It analyzes ATS issues, weak sections, buzzwords, red flags, and suggests stronger bullet points.

##  Features

*  Upload PDF/images or paste resume text
*  Choose Mild, Spicy, or Nuclear roast levels
*  Get an overall resume score
*  AI-powered ATS & resume analysis
*  Identify red flags and weak sections
*  Get improved resume bullet points
*  Dark & light mode
*  Share previous roast results

## Tech Stack

**Frontend:** React 18, Vite, Tailwind CSS, Framer Motion
**Backend:** Node.js, Express.js, Multer
**AI:** Google Gemini API + local fallback analysis
**Database:** PostgreSQL
**Other:** Formspree, PDF parsing

## How It Works

1. Upload your resume or paste the text.
2. Select a roast level.
3. Click **Roast**.
4. Get your score, flaws, red flags, and improvement suggestions.
5. Fix your resume and become slightly less roastable.
